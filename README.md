# Мила • 1-4 «Сакуровый лес» — игра-платформер (Godot 4.7)

Платформер на **Godot 4.7**: розовая девочка Мила идёт от левого нижнего
флажка ⚑ до крайнего правого храма с крутящейся розовой воронкой.
Игра портирована с HTML5/Canvas-версии (она сохранена в `legacy_web/`).

## 🌐 Играть в браузере (GitHub Pages)

В папке [`docs/`](docs/) лежит полностью рабочая **HTML5/Canvas-версия** игры —
с той же картой, героиней, врагами, предметами, порталом и фоновой музыкой,
что и в Godot-версии. Она не требует установки и запускается прямо в браузере.

1. В настройках репозитория: **Settings → Pages → Build and deployment →
   Source: Deploy from a branch**, ветка `main`, папка `/docs` → **Save**.
2. Через минуту-две игра будет доступна по адресу
   `https://narc1ssa.github.io/cuty/`.

Локально веб-версию можно проверить, подняв любой статический сервер из `docs/`
(подробности — в `docs/README.md`), например:

```bash
cd docs && python3 -m http.server 8080
```

и открыть `http://localhost:8080`.

## Как запустить

1. Установите редактор **Godot 4.7** (godotengine.org/download).
2. В Godot: **Import** → выберите файл `project.godot` в корне репозитория → Open.
   Редактор сам импортирует все картинки (`map.png`, спрайты и т.д.).
3. Нажмите **▶ Run Project (F5)** — главная сцена `scenes/Main.tscn`.

Экспорт в exe/web: Project → Export… (нужны export templates для 4.7),
пресет добавляется одной кнопкой Add… — настройки проекта это не требуют.

## Управление

| Клавиши | Действие |
|---|---|
| `←` `→` / `A` `D` | движение |
| `↑` / `W` / `Пробел` | прыжок, в воздухе — ещё раз (двойной прыжок) |
| `Z` / `J` или мышь | ⭐ звёздный бластер — бесконечный боезапас |
| `X` | 💗 сердечный выстрел — двойной урон, 3 заряда (медленно восстанавливаются) |
| `C` | 🐇 выстрел-зайчик — пробивает насквозь нескольких врагов, 6 зарядов |
| `P` / `Esc` | пауза |
| `M` | звук и музыка вкл/выкл |
| `R` | уровень заново, `Enter` — старт из меню |

На сенсорных экранах появляются экранные кнопки (кнопки HUD).

## Структура проекта

```
project.godot          настройки проекта Godot 4.7 (1280x720, GL Compatibility)
scenes/
  Main.tscn            главная сцена (корень — Node2D со скриптом main.gd)
  Player.tscn          Мила: CharacterBody2D + Sprite2D + Camera2D
  Enemy.tscn           враг: Area2D (патруль своей платформы)
  Bullet.tscn          звёздочка-снаряд: Area2D
scripts/
  main.gd              уровень: платформы по map.png, спавн врагов/предметов,
                       чекпоинты, комбо, камера и параллакс, победа/поражение
  player.gd            движение, двойной прыжок (койот-тайм+буфер), стрельба, HP
  enemy.gd             патруль в пределах своей платформы, HP, полёты у мышей
  bullet.gd            полёт звёздочки, попадание по врагу
  portal.gd            анимированная крутящаяся розовая воронка (спирали, орбиты)
  clouds.gd            дальний параллакс-слой (облака и кроны, x0.45 скорости мира)
  petals.gd            передний план: падающие лепестки сакуры трёх глубин + веточки
  items.gd             отрисовка монет, кристаллов и сердечек
  hud.gd               весь интерфейс кодом (профиль, сердечки, комбо, таймер,
                       энергия, прогресс флаг->портал, тост, экраны, тач-кнопки)
  sfx.gd               синтезированные звуки (AudioStreamWAV, без файлов)
assets/sprites/        спрайты Милы и врагов (PNG с прозрачностью)
tools/extract_sprites.py  вырезает спрайты из hero_bck.png / enemies.png
legacy_web/            архив исходной веб-версии (HTML5 Canvas)
```

## Что реализовано (как в исходной игре)

- **Карта** `map.png` (2861×768) — 23 платформы в `main.gd` (`PLATFORMS`)
  размечены по нарисованным платформам карты, все «односторонние»
  (CollisionShape2D с one_way_collision): приземление сверху, прыжок снизу.
- **Мила** — позы из `hero_bck.png` (лист на сером фоне; белый фон старого
  `hero.png` давал просвечивание белой одежды, поэтому спрайты вырезаются
  заливкой фона по связности — `tools/extract_sprites.py`).
- **Враги** — 12 врагов 6 видов из `enemies.png` (слизень, летучая мышь,
  паук, гриб, шипач, бесёнок); **каждый патрулирует только свою платформу**
  (`ENEMY_SPAWNS` в `main.gd`: платформа + участок), мыши парят над ней.
- **Панель способностей** (по макету `HUD.png`): ⭐ звёздный бластер (`Z`,
  бесконечно, тратит энергию), 💗 сердечный выстрел (`X`, двойной урон,
  3 ограниченных заряда) и 🐇 выстрел-зайчик (`C`, пробивает насквозь
  нескольких врагов подряд, 6 ограниченных зарядов) — заряды X/C медленно
  восстанавливаются сами, как энергия бластера. HP и полоски здоровья врагов,
  комбо, частицы (CPUParticles2D), всплывающие очки, монеты/кристаллы/сердечки,
  чекпоинты, шипастые колёса, пропасти, пауза, экраны победы/поражения, статистика.
- **Музыка** — две реальные дорожки, `music.mp3` и `music_soft.mp3`, играются по кругу
  одна за другой бесконечно (как только одна заканчивается — сразу начинается
  следующая), управляется вместе со звуком (клавиша `M`).
- **Лепестки сакуры** падают в трёх глубинах, а слои движутся с разной
  скоростью (**параллакс**: облака ×0.45, мир ×1.0, лепестки и веточки спереди).
- **Финал** — храм справа: над порталом анимирована **крутящаяся розовая
  воронка** (`portal.gd`); Мила втягивается в неё → экран победы.

# Мила • 1-4 «Сакуровый лес» — игра-платформер

Платформер по материалам репозитория: розовая девочка Мила идёт от левого
нижнего флажка ⚑ до крайнего правого храма с крутящейся розовой воронкой 🌀.

## Запуск

Нужен локальный сервер (картинки подгружаются из файлов):

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Управление

| Клавиши | Действие |
|---|---|
| `←` `→` / `A` `D` | движение |
| `↑` / `W` / `Space` | прыжок, в воздухе — ещё раз (двойной прыжок) |
| `Z` / `X` / `J` или мышь | стрельба звёздочками из бластера |
| `P` / `Esc` | пауза |
| `M` | звук вкл/выкл |
| `R` | уровень заново |

На сенсорных экранах появляются экранные кнопки.

## Что реализовано

- **Героиня** — спрайты вырезаны из `hero_bck.png` (та же героиня на сером
  фоне; стойка, бег, прыжок,
  выстрел, победа, урон, падение): `tools/extract_sprites.py` превращает
  белый фон листа в прозрачность и сохраняет позы в `assets/sprites/`.
- **Карта** — `map.png` (2861×768). Платформы в `game.js` (`PLATFORMS`)
  размечены по нарисованным деревянным/каменным платформам карты; все
  платформы «односторонние» (приземление сверху, прыжок сквозь них снизу).
- **Враги** — все 6 видов из `enemies.png` (Теневой Малыш, Летучая Мышь,
  Меха-Паук, Грибной Ворчун, Рогатый Громила, Фиолетовый Бесенок).
  Всего 12 врагов, **каждый патрулирует только свою платформу**
  (`ENEMY_SPAWNS`: платформа + участок патруля), летучие мыши парят над ней.
- **Стрельба** — розовые звёздочки-снаряды со вспышками и частицами,
  у врагов есть HP и полоска здоровья; убийства дают комбо ★.
- **Интерфейс** — по макетам `HUD.png` / `preview.png`: портрет Милы,
  5 сердечек, монеты ⭐ и кристаллы ♦, баннер «1-4 • Сакуровый лес»,
  комбо, таймер, полоса энергии бластера, прогресс пути флаг → портал,
  предупреждение «Осторожно! Враги!», подсказки управления.
- **Лепестки сакуры** — на фоне постоянно падают мелкие розовые лепестки
  трёх глубин: качаются, крутятся и опадают с разной скоростью.
- **Параллакс** — при движении Милы слои сдвигаются с разной скоростью:
  далёкие облака и кроны (×0.35–0.55), карта с платформами (×1.0),
  лепестки разной глубины и веточки сакуры на переднем плане (×1.2).
- **Финал** — достижение храма справа: над порталом на карте анимирована
  крутящаяся розовая воронка (спирали, орбитальные звёздочки, пульсация);
  Мила втягивается в неё, после чего показывается экран победы со статистикой.
- Прочее: чекпоинты (старт, сундук, беседка), монеты/кристаллы/сердечки,
  шипастые колёса, урон и неуязвимость после удара, падение в пропасть,
  экраны паузы / победы / поражения, синтезированные звуки (WebAudio),
  сенсорное управление.

## Файлы

- `index.html`, `style.css`, `game.js` — игра (Canvas, без зависимостей)
- `assets/sprites/` — вырезанные спрайты героини и врагов
- `tools/extract_sprites.py` — генератор спрайтов из `hero.png` / `enemies.png`
  (запуск: `python3 tools/extract_sprites.py`, нужен Pillow)
- `map.png`, `hero.png`, `enemies.png`, `enemies2.png`, `HUD.png`,
  `preview.png`, `map_preview.png` — исходные материалы

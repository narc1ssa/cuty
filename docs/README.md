# Мила • Сакуровый лес — веб-версия (HTML5/Canvas)

Эта папка — самостоятельная статическая веб-игра, готовая к публикации через
**GitHub Pages** (Settings → Pages → Source: ветка `main`, папка `/docs`).

Файлы:

```
index.html   разметка экранов (меню, HUD, пауза, победа/поражение)
style.css    оформление интерфейса
game.js      вся логика игры на canvas (физика, враги, предметы, камера,
             параллакс, портал, звуковые эффекты — Web Audio API + shot.wav)
map.png      карта уровня (копия из корня репозитория)
music.mp3        основная фоновая мелодия (копия из корня репозитория)
music_soft.mp3   мягкая фоновая мелодия (копия из корня репозитория)
shot.wav         звук выстрела (копия из корня репозитория)
assets/sprites/  спрайты героини и врагов (копия из корня репозитория)
```

Игра соответствует актуальной версии на Godot 4.7 (см. `../README.md` и
`../scripts/`): те же платформы, враги, монеты/кристаллы/сердечки, портал
и чекпоинты, плюс фоновая музыка — `music.mp3` и `music_soft.mp3` играются
по кругу друг за другом бесконечно, как в `../scripts/music.gd`, и панель
способностей (`Z`/`X`/`C`) из `../scripts/player.gd`: ⭐ звёздный бластер
(бесконечно), 💗 сердечный выстрел (двойной урон, 3 заряда) и 🐇 выстрел-
зайчик (пробивает насквозь, 6 зарядов) — заряды X/C восстанавливаются сами
со временем.

## Запуск локально

Открыть `index.html` напрямую через `file://` браузер может не дать
загрузить картинки (CORS), поэтому запускайте через любой статический сервер:

```bash
cd docs
python3 -m http.server 8080
# откройте http://localhost:8080
```

## Обновление ассетов

Если карта или спрайты обновятся в корне репозитория (`map.png`,
`assets/sprites/*.png`), скопируйте их заново в `docs/` и `docs/assets/sprites/`.

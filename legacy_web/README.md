# Архив веб-версии

Здесь лежит прежняя HTML5/Canvas-версия игры (`index.html`, `style.css`, `game.js`),
как референс логики, с которой портировалась Godot-версия.

**Рабочая, обновлённая HTML5-версия для GitHub Pages лежит в [`../docs/`](../docs/)**
(собрана на основе этого архива + копии актуальных ассетов + фоновая музыка,
как в Godot-версии). Актуальная полнофункциональная версия игры — проект
Godot 4.7 в корне репозитория (см. `../README.md`).
